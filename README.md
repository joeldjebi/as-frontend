# Adjamé-Smart — back-office

React + Vite. Équipe Adjamé-Smart : validation des boutiques et des revendeurs, catégories, clients, équipe.

```bash
npm install
npm run dev            # http://localhost:5174 (API : VITE_API_URL, par défaut http://localhost:3100)
VITE_API_URL=https://api.as.performx.online npm run build   # production → dist/
```

Thème par défaut : vert #0F8A5F, à remplacer par l'identité visuelle définitive (variables `--primary`, `--accent` dans `src/styles.css`).
